## Nosso Objetivo 

  Desenvolver um projeto de engenharia de software que apresente um produto, um plano de desenvolvimento, documentação UML.
  
  Escolhemos desenvolver uma plataforma de empregos que coloca o trabalhador como centro da operação, com uma vitrine personalizável, com seus serviços, produtos e destaques servindo também como página de contratação.
  
  - Website: [https://fortech-jobs.vercel.app](https://fortech-jobs.vercel.app)
  - Documentação: <a href="https://docs.google.com/document/d/1hUIp3p3grt_vvF26tpLqrfuk6tvvpqc66KJXw8AnTjs/edit?usp=sharing" target="_blank"> Clique aqui </a>

  > Note que o link acima possui um campo REFERÊNCIAS com demais documentos: Documento de Conceito, Visão Geral, Plano de Testes, Documentação UML, Ata de Apresentação.
